<h2 id="how-it-works" class="section-title">How it works</h2>

<Steps>

1. **Paste links.** One URL, a whole list, or a text file. The
   [Firefox extension](/scraper/guides/browser-extension/) can export your open
   tabs straight into one.

2. **Preview.** `--dry-run` resolves every album and shows the file count and
   total size before anything downloads.

   ```bash
   scraper --dry-run https://filester.sh/f/FOLDER_ID
   ```

3. **Download.** Files stream in concurrently with live progress, per-host
   limits, and automatic backoff when a site rate-limits you.

   ```bash
   scraper -i urls.txt
   ```

4. **Retry what failed.** Anything that didn't finish is saved to a retry list
   you can replay later; partial files resume where they stopped.

   ```bash
   scraper --input-file ~/Downloads/scraper-failed-*.txt
   ```

</Steps>
